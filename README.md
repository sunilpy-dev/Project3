# 🎬 Netflix Clone

A responsive **Netflix landing page clone** built using **pure HTML and CSS**.  
This project recreates the look and feel of Netflix’s homepage, including the hero section, feature sections, FAQ area, and footer, while focusing on **layout design, responsiveness, and modern UI styling**.

---

## 🌟 Project Overview

This project was built to practice and understand how **large-scale, real-world websites** like Netflix structure their UI and layouts.  
It demonstrates how **HTML semantic elements**, **CSS Flexbox, Grid, positioning, and media queries** work together to create a polished, production-style landing page.

The design includes:
- A Netflix-style hero section with call-to-action  
- Feature sections with images and videos  
- FAQ accordion-style layout  
- Fully responsive layout for different devices  

---

## 🖼️ Features Implemented

- **Hero section** with background image, overlay, and email input  
- **Responsive navigation bar** with logo and action buttons  
- **TV & mobile preview sections** using layered images and videos  
- **Kids profile section**  
- **FAQ section** with hover effects  
- **Footer with multi-column layout**  
- **Mobile and tablet support** using media queries  

---

## 🛠️ Technologies Used

- **HTML5** — semantic page structure  
- **CSS3**  
  - Flexbox  
  - Grid  
  - Media Queries  
  - Positioning & layering  
  - Hover effects and transitions  
- **Google Fonts** (Poppins, Martel Sans)  

No JavaScript is used — this is a **static UI clone** focused on frontend layout and design.

## ▶️ How to Run the Project

1. Download or clone the repository  
2. Open the project folder  
3. Open `index.html` in any modern web browser  

That’s it — no installation or setup required.

---

## 📱 Responsive Design

This project includes **media queries** to adapt the UI for:
- Desktop screens  
- Tablets  
- Mobile devices  

The layout, text size, images, and grid structure adjust automatically based on screen width.

---

## 🎯 What This Project Demonstrates

This project shows:
- Real-world landing page layout design  
- CSS positioning and layering (overlay, background, videos inside images)  
- Responsive UI using media queries  
- Use of Flexbox and Grid together  
- Clean HTML structure
